`fsdiff` compares the filesystem between two different time points and reports the differences.

## Installation

You can download the pre-built binaries from the [GitHub Releases](https://github.com/mycrEEpy/pakku/releases) or use various other installation methods.

Using Go:

```shell
go install github.com/mycreepy/fsdiff/cmd/fsdiff@latest
```

Using Pkgx:

```shell
pkgx pkgm install github.com/mycreepy/fsdiff
```
